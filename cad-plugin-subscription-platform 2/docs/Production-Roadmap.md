# Production Roadmap

## MVP

- Pendrive installer.
- AutoCAD bundle autoload.
- Manifest-based LISP loading.
- Manual license activation command.
- Admin scripts to add/remove LISP tools.

## Commercial Beta

- Customer portal.
- Admin dashboard.
- Subscription checkout.
- License key generation.
- Device activation limit.
- Installer download per customer.
- Basic update check.

## Production

- Signed license tokens.
- Compiled AutoCAD loader.
- Encrypted LISP packages.
- Tool versioning and rollback.
- Subscription expiry enforcement.
- Device deactivation and transfer workflow.
- Enterprise license pools.
- Audit logs.

## Marketplace Vision

- Vendor/developer accounts.
- Tool review and approval workflow.
- Paid industry bundles.
- Civil, survey, architecture, and drafting categories.
- Multilingual command documentation.
- Region-specific workflows for India.
